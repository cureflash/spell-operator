# Spell Operator Map Editor

実装: `tools/tilemap-editor.html`

## 対象マップ

- `town` — フルール村
- `school` — 学校
- `library` — ピジブルの図書館
- `house1` — ソフィーの家 1F
- `house2` — ソフィーとルミエルの部屋 2F
- `la_mer_city` — ラメールシティ

マップ選択ごとに編集データを分離して保存する。幅・高さ、床・壁、家具、上層、当たり判定を編集できる。

## パレット

パレットは `素材セット → 種類 → バリエーション` の3段階で切り替える。

### 登録済み素材セット

- ドット絵世界
  - 部屋
    - 女の子の部屋（ローカル読込）
- Pipoya FREE RPG Tileset 32x32
  - 基本・家具/建物 — BaseChip
  - 草地 — Grass1〜4
  - 土・道 — Dirt1〜4
  - 水 — Water1〜7
  - 壁 — Wall-Up1〜2
  - 装飾 — Flower / LongGrass

Pipoyaはゲーム本体で既に利用している32×32素材の参照先をエディタでも使用する。素材PNGをSpell Operatorリポジトリへ複製しない。

各配置セルは単なる通し番号ではなく、`palette id + x/y chip coordinate` を保持する。このためパレットを切り替えても既に配置した別素材のチップは残り、同じマップで複数素材セットを混在できる。

旧エディタの数値タイルIDは読み込み時に `dotart-room` の座標参照へ自動変換する。

## 複数チップ選択・スタンプ

パレット上でドラッグすると32×32チップを矩形でまとめて選択できる。

例: ベッドが縦3チップで構成されている場合、パレット上で `1×3` を選択し、マップ上の配置先を1回クリックすると3チップを一括配置する。

- 1クリック: 選択中の矩形スタンプを配置
- ドラッグ: 同じ矩形スタンプを連続配置
- 右クリック / 右ドラッグ: 選択矩形と同じ範囲を消去
- Shift + マップ上をクリック: そのセルの素材セットとチップをスポイト

## 通常ゲームとプレビューの分離

エディタのブラウザ保存データ `spell-operator-tilemap:<mapId>` は、通常ゲームでは読み込まない。

- 通常ゲーム: GitHub上の正式なゲームマップ定義・画像だけを使用する。
- 編集プレビュー: URLに `?mapedit=1` がある場合だけ、`js/tilemap-runtime.js` がブラウザ保存の編集データを読み込む。

このため、エディタでの作業や古いlocalStorageデータが通常ゲームを勝手に書き換えることはない。
正式マップへ採用する場合は、プレビュー確認後にGit側の正式マップデータへ反映する。

`assets/maps/house2-layout.json` はエディタの初期案データとして使用し、通常ゲームの強制上書きには使用しない。

## house2 イベント配置

`house2` は以下のイベント座標をエディタ上で移動できる。

- `P` / `pc` — パソコン
- `S` / `stairs` — 1Fへ降りる階段
- `A` / `playerStart` — 新規ゲーム時のソフィー開始位置
- `B` / `followerStart` — 新規ゲーム時のルミエル開始位置

イベントボタンを選択してからマップ上の移動先セルをクリックする。配置先セルの当たり判定は自動的に通行可能へ変更する。

編集プレビュー時だけ `js/tilemap-runtime.js` が保存されたイベント座標を優先する。

## その他マップ

現時点ではタイル、当たり判定、サイズの編集に対応する。各マップ固有の入口・NPC・アイテム等のイベント座標編集は未対応。

## 大規模マップ

ラメールシティ等の大規模マップでカスタムマップを使う場合、大量のDOMタイルを再生成せず、完成画像レイヤーと論理当たり判定を使用する。
