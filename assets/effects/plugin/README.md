# Plug-in transition assets

- `kirayuki1.webp`: user-supplied `キラ雪.zip / kirayuki1.png` converted to a lightweight 10-frame WebP sprite sheet for the plug-in transition.
- The matching user-supplied sparkle SE is stored as `assets/audio/sfx/plugin-sparkle.base64` and decoded to audio/mpeg at runtime.
- These assets are used only by the normal-field Lumiere plug-in transition.
